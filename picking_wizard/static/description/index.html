Overview

This module allows you to edit the picking lines using a wizard in the list view without opening the record
Edit the picking lines directly from the tree view

Features

- Edit picking lines without opening the record
- Allow you to define the location source and the destination of each picking line
- Allows to change the quantity done for each line without opening the record
